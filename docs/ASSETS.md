# Local portrait presets

Four original preset photographs were generated with the built-in image generation tool on 2026-09-08 and copied into the project. They are standalone local assets, not runtime image API calls. Original hairstyle, hair color and mock input images are retained.

Shared brief: a single vertical 2:3 head-and-shoulders portrait photograph of an adult woman, full head visible with comfortable margin; final stylized photo for an AI photo template catalog; no UI, text, logos, or watermark.

| Saved project asset | Final scene prompt |
| --- | --- |
| `public/assets/portraits/classic.png` | Classic fine-art studio portrait, elegant white shirt, natural dark hair, warm grey seamless background, soft Rembrandt lighting, timeless museum portrait photography. |
| `public/assets/portraits/dreamy.png` | Dreamy portrait in soft chiffon, lilac and pale pink garden bokeh, delicate diffused sunlight, airy romantic atmosphere, believable skin, fine-art photography. |
| `public/assets/portraits/vintage.png` | Vintage 1970s portrait, warm analog film grain, cream blouse, warm brown studio backdrop, nostalgic window light. |
| `public/assets/portraits/editorial.png` | Black-and-white fashion editorial portrait, dark tailored blazer, slick hair, strong sculptural directional studio lighting, magazine photography. |

These are Mock template previews; generation in the prototype displays the selected preset and stores the current AI profile association. It does not synthesize that person's identity into the image.
